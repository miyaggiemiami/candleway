The Netlify deploy errored, with the following guidance provided:

The build is failing because npm is trying to fetch `lightweight-charts` from a Replit-local package registry (`http://package-firewall.replit.local/...`) as seen at [line 26](#L26). This indicates the `package-lock.json` was generated inside a Replit environment and contains a Replit-specific registry URL that is not accessible on Netlify's build servers.

**Solution:**

1. Delete your `package-lock.json` file locally (not in Replit).
2. Run `npm install` in your local environment to regenerate a clean `package-lock.json` pointing to the public npm registry.
3. Commit and push the new `package-lock.json` to your repo:

```bash
rm package-lock.json
npm install
git add package-lock.json
git commit -m "Regenerate package-lock.json with public registry"
git push
```

This will ensure Netlify fetches `lightweight-charts` and all other packages from the standard npm registry instead of the Replit-internal proxy.
